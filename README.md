# 🖼️ Lấy Ảnh Từ DOCX & PDF - D.T.Chánh

Ứng dụng web giúp bạn dễ dàng trích xuất ảnh gốc từ file Word (`.docx`), tách ảnh nhúng từ file `PDF` và chuyển đổi các trang tài liệu `PDF` thành hình ảnh chất lượng cao một cách nhanh chóng, an toàn và hoàn toàn offline ngay trên trình duyệt.

---

## 🌟 Tiện Ích Cho Người Dùng

* **Tải file tiện lợi:** Kéo thả file, bấm chọn hoặc dán trực tiếp bằng phím tắt `Ctrl + V` từ bộ nhớ tạm.
* **Lọc bỏ ảnh nhỏ & rác:** Tự động loại bỏ các biểu tượng, icon rác kích thước nhỏ bằng bộ lọc chiều rộng/chiều cao tối thiểu.
* **Trích xuất PDF đa năng:** 
  * *Lấy ảnh gốc:* Thu về trọn vẹn các hình ảnh minh họa nhúng sẵn bên trong tài liệu PDF.
  * *Chụp cả trang:* Chuyển đổi các trang tài liệu PDF thành file ảnh JPG sắc nét. Hỗ trợ chọn trang cần lấy (ví dụ: `1, 3, 5-8`), chỉnh độ phân giải ($2\text{x}, 4\text{x}, 6\text{x}$) và chất lượng ảnh.
* **Xem trước & Tải về linh hoạt:**
  * Xem ảnh phóng to và kiểm tra kích thước, dung lượng từng ảnh trước khi tải.
  * Tải từng ảnh lẻ, tải toàn bộ ảnh thuộc trang đang xem dưới dạng file `.zip`, hoặc tải tất cả ảnh trong tài liệu chỉ với 1 cú nhấp chuột.
* **Bảo mật tuyệt đối & Chạy offline:** Toàn bộ quá trình xử lý diễn ra trực tiếp trên thiết bị của bạn, không tải file lên mạng, đảm bảo an toàn dữ liệu và sử dụng mượt mà không cần kết nối internet.

---

## 🛠️ Hướng Dẫn Sử Dụng

1. **Nạp tài liệu:** Kéo thả, bấm chọn file `.docx` / `.pdf` hoặc nhấn `Ctrl + V`.
2. **Tuỳ chỉnh:** Chọn chiều rộng/chiều cao tối thiểu để lọc bớt ảnh rác, chọn trang PDF hoặc độ phân giải mong muốn, sau đó nhấn **Áp dụng** (hoặc phím **Enter**).
3. **Tải về:** Nhấp vào từng ảnh để tải lẻ hoặc chọn **Tải xuống (.zip)** để lưu hàng loạt về máy.
